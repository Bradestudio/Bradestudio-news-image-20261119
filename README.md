Thursday 19 November 2026 in one image: a newspaper front page drawn
programmatically — 44 stories across 6 continents, all date-checked.
Lead: Democrats nominate Jeffries for Speaker (251–11); Trump, Xi and
Putin meet in Shenzhen; GTA VI launches worldwide; Voyager 1 reaches one
light-day out; Cyclone Akvan turns very severe; the ICJ rules on the
Rohingya case; Anthropic prices its IPO at $83; and a Van Gogh sells for
a record $190.4m.

One deterministic 1024×1024 PNG, rendered by a Python program (Pillow,
build-time only, no network, no external assets). The shipped main.py
only copies the PNG to the output directory; gen_image.py draws it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Regenerate the image from scratch (needs Pillow, build-time only):

```sh
python3 gen_image.py
```
